      About Converter

      How to use

      1. Drop or click to select files (images, GIF, audio, video, documents, AutoCAD/DWG/DXF, 3D models)
      2. Choose a target format from the dropdown (GIF keep animation via FFmpeg)
      3. Pick an output folder
      4. Click Convert

      Supported formats

      Image JPEG, PNG, WEBP, BMP, TIFF, GIF (animated + static), AVIF, HEIC/HEIF, JP2, JXL, APNG, SVG, PSD, ICO, HDR/EXR, TGA/DDS, RAW (CR2/CR3/NEF/ARW/DNG/RAF/ORF/RW2...), PPM/PGM/PBM
      GIF special GIF ↔ MP4/WEBM/MOV/AVI/MKV, GIF ↔ WEBP/APNG/JXL, GIF optimalisatie, video → GIF met palette
      Audio MP3, WAV, OGG, FLAC, AAC/M4A/M4B, WMA, OPUS, AIFF, ALAC, AC3, MP2, WavPack (WV), MKA, CAF, DTS
      Video MP4, AVI, MOV, MKV, WEBM, WMV, FLV, 3GP, M4V, MPG/MPEG, OGV, TS/MTS/M2TS, MXF, HEVC/H264/H265, AV1/VP9, GIF, WEBP, APNG, DV, RM
      Document PDF ↔ TXT/HTML/MD/CSV/JSON, DOCX/DOC → PDF/TXT/HTML/JSON, HTML/MD ↔ PDF/TXT, CSV ↔ JSON, RTF, XML/YAML, ODT/ODS/ODP/XLS/PPT (via LibreOffice hint)
      AutoCAD & CAD DWG/DXF → 3D (GLTF/GLB/STL/OBJ/PLY) én DXF; DWF/DWFX → PNG/JPG/PDF via sheet-previews (DWF-3D zelf kan niet naar 3D, exporteer dan als DWG)
      SketchUp SKP, SKB (via openskp 1.1 → GLB/GLTF/STL/OBJ/PLY/DXF/IFC/JSON, en via GLB→DAE/FBX/USD)
      3D Model 3DS, 3MF, AC, AMF, ASE, ASSBIN, B3D, BLEND, BVH, CSM, Collada (DAE), DXF, FBX, GLTF/GLB, HMP, IFC, IRR, LWO/LXO/LWS, MD2/MD3/MD5, MDC, MDL, MS3D, NDO, NFF, OBJ, OFF, OGEX, PLY, PMX, Q3D, RAW, SIB, SMD, STL, STP/STEP, TER, USD/USDA/USDC/USDZ, VRM, X/X3D/XGL, 3DM, BREP, C4D, + SKP/SKB
      3D Export GLTF, GLB, STL, OBJ, PLY, FBX, DAE, DXF, USD, IFC (SketchUp direct; andere via assimp)
      BIM IFC (via assimp & openskp), USD/USDA, STEP/STP, IGES/IGS
      Archive ZIP, JAR/WAR/EAR/APK/AAB (zip-based), TAR/TGZ, GZ/BZ2/XZ, 7Z/RAR/CAB/ISO (via 7-Zip) — onderling converteerbaar via extract → re-pack
      Animation Lottie (.lottie + .json), GIF, WEBP

      Tips

      • Hold Ctrl/Cmd to select multiple files
      • GIF: animated GIF → MP4/WEBM/WEBP/APNG behoudt animatie via FFmpeg; static GIF → JPG/PNG via sharp
      • AutoCAD: DWG (R12-2018+) via WASM → DXF → GLTF/GLB/STL/OBJ/PLY
      • SketchUp: SKP/SKB (2021+ VFF + 2013-2020 legacy) → GLB, STL, OBJ (+MTL), PLY, DXF, IFC, JSON via openskp; SKP → DAE/FBX via GLB → assimp
      • 3D/BIM: GLTF/GLB/STL/OBJ/PLY/FBX/DAE/DXF/USD/IFC/STEP/IGES/3DM voor alle model types
      • Images: RAW (CR2/NEF/ARW/DNG...), PSD, JXL, HDR, ICO → JPG/PNG/WEBP via sharp met FFmpeg fallback
      • Documents: PDF ↔ TXT/HTML/MD/JSON/CSV, DOCX → PDF/TXT/HTML/JSON, MD → HTML, CSV ↔ JSON, RTF → TXT
      • Archives: ZIP/JAR ↔ TAR/TGZ/GZ/BZ2/XZ, ZIP ↔ 7Z/RAR (vereist 7-Zip), alle archieven onderling converteerbaar
      • Lottie animations → MP4, GIF, WEBP
      • Large video/GIF/SKP files may take longer
      • Media Player now previews images, GIF, video & audio with search, filters and shuffle
      • Windows dropdown wit-op-wit is gefixed (donkere popup)
